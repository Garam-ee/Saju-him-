Gunghap is not a vibe. It is five specific comparisons between two charts, each worth points, added up and scaled.

What gunghap compares

Day masters against each other, day branches, year branches, which elements each chart is short of, and how far each leans yin or yang. Five axes, five numbers.

Why one number is not the answer

Two couples can land on the same score for completely different reasons — one held together by a locked branch pair, another by covering each other's shortages. The number is a summary of the working, not a verdict.

Where it is used

Korean families check gunghap before a wedding. Her friends check it before the second date. Same tool, different stakes.
